# #⌨️ Set Period

Returns current year and month name if the flag is defaulted to `true`. Returns current year and next month name if flag is `false`.
## Parameters

| data type | variable name | metadata | default value |
| --------- | ------------- | -------- | ------------- |
| boolean   | timestamp     |          | True          |
## Return

| condition | data type | value      |
| --------- | --------- | ---------- |
| success   | str       | year month |
## Code

```python
def period(current=True):
    now = DT.now()
    if not current:
        now += TD(days=28)
    return now.strftime('%Y %D')
```
