# #⌨️ Lambda Functions

## File Context Replacer

Sets the value of a context item from path/file variables to be the same as the variable with the same name if the item is enclosed in {{}}

```python
process = lambda item: globals().get(item[2:-2]) if item.startswith("{{") and item.endswith("}}") else item
```
