# #⌨️ File Importer

If the file extension is csv, reads the `filepath` and returns a list of lists. Else, reads the `filepath` and returns a dictionary.

## Parameters

| data type | variable name | metadata               | default value |
| --------- | ------------- | ---------------------- | ------------- |
| str       | path          | local folder addresses | {}            |
| str       | file          | local file addresses   | {}            |

## Return

| condition | data type | value         |
| --------- | --------- | ------------- |
| csv       | str       | data          |
| json      | dict      | data          |
| fail      | str       | error message |

## Code

```python
import json, os, csv

def read_file(path, file):
    full = os.path.join(path, file)
    try:
        if full.lower().endswith('.csv'):
            with open(full, 'r') as csv_file:
                reader = csv.reader(csv_file)
                data = [row for row in reader]
            return data
        elif full.lower().endswith('.json'):
            with open(full, 'r') as json_file:
                data = json.load(json_file)
            return data
        else:
            raise ValueError(f"Unsupported file format at path: {full}")
    except FileNotFoundError:
        raise FileNotFoundError(f"File not found at path: {full}")
```
