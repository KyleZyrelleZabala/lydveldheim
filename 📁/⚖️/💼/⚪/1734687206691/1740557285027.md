# #⌨️  Table Checker

Displays the number of rows and columns of a table as well as the first 10 rows.
## Code

```python
def checkData(df):
    log('\nColumns: '+str({i: item for i, item in enumerate(df)}))
    log('\nRows: '+str(len(df)))
    log(str(df.head(10)))
    return df
```
