# #⌨️ Read Log

Reads the log file from the end. Extracts all characters before a delimiter beginning from the end of the file. Reverses and returns the extracted timestamp and message
## Return

| condition | data type | value          |
| --------- | --------- | -------------- |
| success   | str       | output message |
## Code

```python
def log_read():
    with open(file['log'], 'rb') as data:
        data.seek(0, 2)  # Move the cursor to the end of the file
        size = data.tell()  # Get the size of the file
        
        line=False
        last=bytearray()
        for _ in range(size):
            data.seek(-1, 1)  # Move the cursor back by one character
            char = data.read(1)  # Read one character
            if char == b'\x99' and line: # break after '•' if the extracted message is not empty anymore
                if line:
                    break
                else:
                    line = True
            elif line:
                last.append(char[0])
        return (last[::-1]).decode('utf=8', errors='ignore').split('•')
```
