# #⌨️ Get Excel Data

Extracts an excel sheet into a `dataframe`
## Parameters

| data type | variable name | metadata               | default value |
| --------- | ------------- | ---------------------- | ------------- |
| str       | path          | folder of excel file   |               |
| str       | file          | excel file             |               |
| str       | sheet         | spreadsheet            |               |
| str       | info          | additional information |               |
## Return

| condition | data type | value         |
| --------- | --------- | ------------- |
| success   | dataframe | data          |
| fail      | str       | error message |
## Code

```python
def getData(path, file, sheet, info):
    full = os.path.join(path, file)
    if not os.path.exists(full):
        return log(f"Error: File '{file}' does not exist in {path}.")
    try:
        df = pandas.read_excel(full, sheet_name=sheet)
        return df
    except Exception as e:
        return log(f"Error: Unable to read table in sheet '{sheet}': {str(e)}")
```
