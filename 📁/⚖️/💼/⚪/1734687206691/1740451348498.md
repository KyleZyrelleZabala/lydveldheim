# #⌨️ Save Log

Writes a new activity message at the end of the file
## Parameters

| data type | variable name | metadata                  | default value         |
| --------- | ------------- | ------------------------- | --------------------- |
| int       | index         | logs a unique activity ID | unix timestamp of now |
| str       | timestamp     | logs the date and time    | {{now}}               |
| str       | user          | logs the user             | {{user}}              |
| str       | activity      | logs the activity         |                       |
## Return

| condition | data type | value          |
| --------- | --------- | -------------- |
| success   | str       | output message |
## Code

