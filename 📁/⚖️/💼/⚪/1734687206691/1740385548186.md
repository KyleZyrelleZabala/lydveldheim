# #⌨️ Package Importer

Uses `read_file` function to extract library import parameters from `csv` file

## Parameters

```python
app_folder=f'E:\Metropolitan\MAVIS'
```

## Code

```python
for package in (read_file(app_folder,'lib.csv'))[1:]:
    use(package[1],package[2],package[3],package[4])
```
