# #⌨️ Make Folder

Creates a folder at a specified location if it does not exist yet.
## Parameters

| data type | variable name | metadata         | default value |
| --------- | ------------- | ---------------- | ------------- |
| str       | path          | full folder path |               |
## Return

| condition | data type | value               |
| --------- | --------- | ------------------- |
| success   | str       | Folder {{}} found   |
| fail      | str       | Folder {{}} created |
## Code

```python
def folder(path):
    if not os.path.exists(path):
        os.mkdir(path)
        log('Folder created: '+path)
    log('Folder found: '+path)
    return path
```
