# #⌨️ Module Importer

Imports a library or installs it then imports it with a given maximum attempts
## Parameters

| data type | variable name | metadata                   | default value |
| --------- | ------------- | -------------------------- | ------------- |
| str       | module        |                            |               |
| str       | import        |                            | None          |
| str       | alias         |                            | None          |
| int       | tries         | maximum number of attempts | 3             |
## Return

| condition | data type | value          |
| --------- | --------- | -------------- |
| success   | None      | output message |
| fail      | str       | error message  |
## Code

```python
def use(module_name, import_name=None, alias=None, try_max=3):
    final_name = alias or import_name or module_name
    try:
        imported = getattr(__import__(module_name, fromlist=[import_name]), import_name) if import_name else __import__(module_name)
        globals()[final_name] = imported
        return f'Import {final_name} successful'
    except ModuleNotFoundError:
        if try_max > 0:
            print(f'Installing {final_name}')
            subprocess.check_call([sys.executable, "-m", "pip", "install", module_name])
            importlib.reload(site)
            print('System paths reloaded')
            return use(module_name, import_name, alias, try_max - 1)
        else:
            return f'Import {final_name} failed after {try_max} attempts'
```
