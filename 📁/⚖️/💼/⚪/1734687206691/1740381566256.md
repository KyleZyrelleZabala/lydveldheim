# #⌨️ File Importer

If the file extension is csv, reads the `filepath` and returns a list of lists. Else, reads the `filepath` and returns a dictionary.

## Parameters

| data type | variable name | metadata | default value |
| --------- | ------------- | -------- | ------------- |
| str       | path          |          |               |
| str       | file          |          |               |

## Return

| condition | data type | value         |
| --------- | --------- | ------------- |
| csv       | str       | data          |
| json      | dict      | data          |
| fail      | str       | error message |
